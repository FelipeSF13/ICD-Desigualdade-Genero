
# Desigualdade de Gênero no Mercado de Trabalho em São Paulo

Projeto acadêmico desenvolvido para a disciplina de Introdução à Ciência de Dados do Centro Universitário Senac.

## Integrantes

- Felipe Freitas
- Wanessa Gonçalves

## Objetivo

Analisar diferenças de participação, rendimento e distribuição por setor econômico entre mulheres e homens no mercado de trabalho do estado de São Paulo.

## Fonte de dados

IBGE — Pesquisa Nacional por Amostra de Domicílios Contínua (PNAD Contínua).

Período analisado: quarto trimestre de 2025.

## Tecnologias

- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## Estrutura

- `parte 1/`: Notebook e relatório da análise inicial.
- `parte 2/`: Aplicação interativa em Streamlit.
- `dados/`: Base tratada utilizada na aplicação.

## Como executar

### 1. Criar o ambiente virtual

python -m venv .venv

### 2. Instalar as dependências

.venv\Scripts\python.exe -m pip install -r requirements.txt

### 3. Executar a aplicação

.venv\Scripts\python.exe -m streamlit run "parte 2/app.py"
